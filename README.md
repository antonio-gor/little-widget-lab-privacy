# Little Widget Lab privacy and support

Public privacy policy and support pages for Little Widget Lab.

- Privacy: https://antonio-gor.github.io/little-widget-lab-privacy/
- Support: https://antonio-gor.github.io/little-widget-lab-privacy/support.html
- Contact: littlewidgetlab@gmail.com

GitHub Pages publishes the root of the `main` branch, matching the other app privacy repositories on this account. This is a static site with no build step. `.nojekyll` keeps the HTML and assets unchanged.

Only public support/privacy copy and original product artwork belong here. The app codebase is maintained separately in a private repository. Do not add credentials, private release contacts, diagnostics, or personal widget data.
